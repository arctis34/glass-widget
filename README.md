# Glass Widget

Un widget de bureau pour Windows, au style verre dépoli : horloge, calendrier, données du PC (processeur, mémoire, disques, carte graphique, réseau) et raccourcis vers tes applications. Il s'utilise en carte compacte ou en plein écran.

## Télécharger

**[⬇ Télécharger la dernière version](https://github.com/arctis34/glass-widget/releases/latest)**

Sur la page qui s'ouvre, clique sur le fichier `Glass-Widget-Setup-x.y.z.exe`.

## Installer

1. Lance le fichier téléchargé. Un écran d'attente s'affiche quelques secondes.
2. Si Windows affiche **« Windows a protégé votre ordinateur »**, clique sur **Informations complémentaires**, puis sur **Exécuter quand même**. Ce message apparaît parce que l'installeur n'est pas encore signé numériquement.
3. Choisis tes options et clique sur **Installer**. Aucun droit administrateur n'est nécessaire.

Pour mettre à jour, télécharge et lance la nouvelle version : elle remplace l'ancienne en gardant tes réglages.

## Configuration

Windows 11, 64 bits.

## Désinstaller

**Paramètres → Applications → Applications installées → Glass Widget → Désinstaller.**

## Confidentialité

Tout reste sur ton PC. Le widget lit les informations du système et ton fond d'écran localement, et n'envoie aucune donnée.
